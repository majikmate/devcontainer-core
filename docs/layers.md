## os

## sshd

SSH server on port 2222 (keys only, no root) with the keys of the owner's GitHub account.

Dockerfile: `RUN devcon install sshd`

Source: [devcontainer-core](https://github.com/majikmate/devcontainer-core) (`github.com/majikmate/devcontainer-core/pkg/layers`)

Needs the layers: user.

Has a start step: `devcon start` runs it when the container starts.

Commands:

- `devcon ssh-keys`: load the SSH keys of the owner's GitHub account
- `devcon sshd-start`: start the SSH server (root)

Entry in the image label `devcontainer.metadata`:

```json
{
  "id": "devcon/sshd",
  "postAttachCommand": "devcon ssh-keys"
}
```

## user

Creates the development user with zsh and sudo.

Dockerfile: `RUN devcon install user`

Source: [devcontainer-core](https://github.com/majikmate/devcontainer-core) (`github.com/majikmate/devcontainer-core/pkg/layers`)

Needs the layers: os.

Build arguments:

- `USERNAME` (default `dev`): name of the development user
- `USER_UID` (default `1000`): user id
- `USER_GID` (default `1000`): group id

Entry in the image label `devcontainer.metadata`:

```json
{
  "customizations": {
    "vscode": {
      "settings": {
        "terminal.integrated.defaultProfile.linux": "zsh"
      }
    }
  },
  "id": "devcon/user",
  "remoteUser": "dev"
}
```

## Start step (framework)

When at least one installed layer has a start step, `devcon metadata` adds this entry once:

```json
{
  "id": "devcon/start",
  "postStartCommand": "devcon start"
}
```
